What is a Random Number Generator?

A random number generator creates a number within a range you choose. The minimum and maximum values are included.

For example, if you enter 1 as the minimum and 100 as the maximum, the tool can generate any whole number from 1 to 100.

How to Use

1. Enter the minimum number.

2. Enter the maximum number.

3. Click "Generate Random Number".

4. A random number will be displayed instantly.
